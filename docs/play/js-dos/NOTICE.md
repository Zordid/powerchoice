# js-dos

The files in this directory are an unmodified excerpt of
[js-dos](https://js-dos.com) 8.5.3 by Alexander Guryanov (caiiiycuk),
as published on npm (`js-dos@8.5.3`): the player (`js-dos.js`,
`js-dos.css`) and, under `emulators/`, the DOSBox and DOSBox-X backends
and their helpers. js-dos runs DOSBox or DOSBox-X, compiled to WebAssembly,
in the browser. The demo uses DOSBox-X for Power-Choice 3.1, because only it
emulates the VGA blanking that PCHEGA's screen saver relies on.
