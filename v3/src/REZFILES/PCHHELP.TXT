.topic Memory

  ▌ Speicher

Geben Sie hier an, wieviel Speicher ihr Programm benötigt. Power-Choice
entscheidet dann, ob es sich beim Ausführen aus dem Speicher entfernen
muß, um für freien Speicher zu sorgen (kostet etwas Zeit) oder ob es im
Speicher verbleiben kann (geht sehr schnell).

Wenn Sie nicht wissen wieviel Speicher ein Programm braucht, oder falls
Sie sicher sind, daß ein Programm viel Speicher braucht, geben Sie hier
0 an. Eine Eintragung von 0 KBytes bewirkt, daß Power-Choice IMMER so viel
Speicher wie möglich frei macht.

.topic HelpOnDosCommands

  ▌ Dos Befehle ausführen

Generell gibt es zwei Möglichkeiten, DOS Befehle auszufüren:

 1. Die {Dos Shell|DosShell}
 2. Power-Choice verlassen <Alt-X>

Wollen Sie für längere Zeit ohne Power-Choice arbeiten, dann können
Sie es mit <Alt-X> verlassen und später wieder mit PCH starten.

Um zwischendurch einige DOS Befehle auszuführen können Sie einfach
ein Dos Shell Fenster öffnen <F4> und darin arbeiten.

.topic QuickRun

  ∙ Der Quick-Run Modus (QR) ∙

Beim Ausführen von DOS Kommandos haben Sie die Wahl zwischen
maximaler Speicherausnutzung oder schneller Ausführung (QR).

Wählen Sie Quick-Run, dann werden die Befehle sehr schnell ausgeführt
und Power-Choice erscheint sofort wieder.

Anderenfalls wird von Power-Choice der gesamte verfügbare Speicher
für DOS freigegeben. Dadurch bedingt muß Power-Choice nach der Ausführung
der Kommandos neu geladen werden, was etwas mehr Zeit in Anspruch nimmt, als
es beim Quick-Run Modus wäre.

Anmerkung: Für einfache DOS Befehle wie COPY, DEL, REN oder DIR, etc, reicht
der durch Quick-Run zur Verfügung gestellte Speicher voll aus. In der
{Dos Shell|DosShell} empfiehlt es sich daher im Quick-Run Modus zu arbeiten.

.topic HelpOnScreenSaver

 + Der Bildschirm Schoner +

Der Power-Choice Bildschirm Schoner schaltet den Bildschirm nach 5 Minuten
dunkel, falls in dieser Zeit keine Tastatureingaben stattfinden. Haben Sie
ein Paßwort definiert, daß Sie beim Starten des Computers eingeben, dann
müssen Sie zum reaktivieren des Bildschirms auch dieses Paßwort eingeben.
Dabei ist lediglich das Paßwort (ohne Enter) einzugeben. Falls Sie sich
vertippen, drücken Sie einmal <Esc> oder <Enter>. Dadurch wird der
Eingabepuffer wieder vollständig geleert und Sie können das Paßwort erneut
von vorne eingeben.

Während der Bildschirm dunkel geschaltet ist, arbeitet der Computer weiter,
er wird von dem Bildschirm Schoner nicht beeinflusst.

 !! ACHTUNG !!
Wenn Sie Microsoft Windows starten wollen, DARF der Bildschirm Schoner nicht
aktiv sein. Legen Sie deshalb für Windows einen Programm-Menüpunkt an, bei dem
Sie den Bildschirm Schoner deaktivieren.

Anmerkung: Innerhalb von Power-Choice ist der Bildschirm Schoner immer aktiv.

.topic HelpOnClock

 + Die Uhr +

Während Sie in Power-Choice arbeiten, sehen Sie in der oberen rechten Ecke
immer eine Uhr. Falls Sie auch in allen anderen Programmen, die im Textmodus
arbeiten, eine Uhr sehen wollen, so können Sie das einerseits per Option
"Uhr einblenden" in der Programm-Menüpunkt Dialogbox eingeben. Es gibt aber
auch immer die Möglichkeit, die Uhr manuell ein- bzw. auszuschalten. Dazu
müssen Sie nur die linke <Strg> und <Alt> Taste zusammen mit der rechten
<Shift> Taste drücken.
